# Sales Data Analysis SQL Project

## Overview

This project analyzes sales data using SQL to extract business insights.

## Dataset

-   100 sample sales records
-   Fields: order_id, order_date, product, category, region, quantity,
    price, revenue

## Key Analysis

-   Total revenue calculation
-   Revenue by category
-   Monthly sales trends
-   Top-performing products
-   Region-wise performance

## Tools Used

-   MySQL / PostgreSQL
-   SQL (Joins, Aggregations, Group By)

## How to Use

1.  Import `sales_data.csv` into your SQL database as table `sales`
2.  Run queries from `queries.sql`
3.  Analyze results for insights

## Insights Example

-   Identify top revenue-generating products
-   Track monthly performance trends
-   Compare regional sales distribution
